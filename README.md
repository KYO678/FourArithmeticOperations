# たのしい さんすう 🎓

幼稚園児・未就学児向けの視覚的・直感的な算数学習Webアプリです。足し算と引き算を楽しく学べます。

## 特徴

### 🎨 視覚的で直感的
- カラフルなフルーツの絵文字で数を表現
- **10のかたまりで数を理解**（10進法の基礎）
- 10を超えると自動的に新しい行に表示
- アニメーション付きで楽しく学習

### 👶 幼稚園児に最適
- 大きなボタンで操作しやすい（1〜20の数字）
- ひらがなで表記
- **式が常に見える**（「3+5=？」の形式）
- タッチデバイスにも対応

### 🎵 インタラクティブ
- ボタンを押すと音が鳴る
- 正解すると楽しい音楽
- 何度でも繰り返し学習できる

### 📊 10のかたまり表示
- 10個ごとにフレームを分ける
- 例：12 = 10のかたまり + 2個
- 数え間違いを防ぐ
- 繰り上がり・繰り下がりの理解につながる

### ➖ 引き算の視覚的表現
- 絵文字が薄くなり、×印がつく「消える演出」
- 後ろから順番に消えていくアニメーション
- 残った絵文字が強調表示される
- 「何個取ったら何個残る」を直感的に理解

## アプリ構成

### トップページ（index.html）
- 足し算と引き算を選択できるメニュー
- 大きなボタンで操作しやすい

### 足し算アプリ（addition.html）
- 数を合わせる学習
- 10のかたまりで視覚的に理解
- 1〜20の範囲で学習可能

### 引き算アプリ（subtraction.html）
- 数を取る（引く）学習
- 絵文字が消える演出で視覚的に理解
- 引く数より小さい数は選べない仕組み
- 残りの数が強調表示される

## 使い方

### 基本的な流れ

1. ブラウザで `index.html` を開く
2. 「たしざん」または「ひきざん」を選ぶ
3. 式が画面上部に表示される（例：「？+？=？」）
4. 1つめの数を選ぶ（1〜20のボタン）
5. 2つめの数を選ぶ（1〜20のボタン）
   - 引き算の場合、1つめより大きい数は選べません
6. 絵文字で視覚的に数を確認（10のかたまりで表示）
   - 足し算：2つのグループが表示される
   - 引き算：絵文字が消える演出が表示される
7. 「こたえを みる！」ボタンを押す
8. 答えが式と大きく表示される
9. 結果も10のかたまりで視覚的に表示
10. 「もういちど やる！」で繰り返し学習
11. 「🏠 もどる」でトップページに戻る
