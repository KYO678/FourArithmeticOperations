# たのしい たしざん 🍎

幼稚園児・未就学児向けの視覚的・直感的な足し算学習Webアプリです。

## 特徴

### 🎨 視覚的で直感的
- カラフルなフルーツの絵文字で数を表現
- 数字だけでなく、実際のオブジェクトで「数」を理解
- アニメーション付きで楽しく学習

### 👶 幼稚園児に最適
- 大きなボタンで操作しやすい
- ひらがなで表記
- ステップバイステップで迷わない
- タッチデバイスにも対応

### 🎵 インタラクティブ
- ボタンを押すと音が鳴る
- 正解すると楽しい音楽
- 何度でも繰り返し学習できる

## 使い方

1. ブラウザで `index.html` を開く
2. 1つめの数を選ぶ（1〜10）
3. 2つめの数を選ぶ（1〜10）
4. 絵文字で視覚的に数を確認
5. 「あわせると いくつ？」ボタンを押す
6. 答えと全てのオブジェクトが表示される
7. 「もういちど やる！」で繰り返し学習

## 技術仕様

- HTML5
- CSS3（アニメーション、グラデーション）
- Vanilla JavaScript
- レスポンシブデザイン
- Web Audio API（効果音）
