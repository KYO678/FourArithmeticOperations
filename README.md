# たのしい たしざん 🍎

幼稚園児・未就学児向けの視覚的・直感的な足し算学習Webアプリです。

## 特徴

### 🎨 視覚的で直感的
- カラフルなフルーツの絵文字で数を表現
- **10のかたまりで数を理解**（10進法の基礎）
- 10を超えると自動的に新しい行に表示
- アニメーション付きで楽しく学習

### 👶 幼稚園児に最適
- 大きなボタンで操作しやすい（1〜20の数字）
- ひらがなで表記
- **式が常に見える**（「3+5=？」の形式）
- タッチデバイスにも対応

### 🎵 インタラクティブ
- ボタンを押すと音が鳴る
- 正解すると楽しい音楽
- 何度でも繰り返し学習できる

### 📊 10のかたまり表示
- 10個ごとにフレームを分ける
- 例：12 = 10のかたまり + 2個
- 数え間違いを防ぐ
- 繰り上がりの理解につながる

## 使い方

1. ブラウザで `index.html` を開く
2. 画面上部に式（「？+？=？」）が表示される
3. 1つめの数を選ぶ（1〜20のボタン）
4. 式が更新される（例：「3+？=？」）
5. 2つめの数を選ぶ（1〜20のボタン）
6. 絵文字で視覚的に数を確認（10のかたまりで表示）
7. 「こたえを みる！」ボタンを押す
8. 答えが式と大きく表示される
9. 結果も10のかたまりで視覚的に表示
10. 「もういちど やる！」で繰り返し学習
